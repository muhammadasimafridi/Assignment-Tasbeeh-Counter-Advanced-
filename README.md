# 📿 Tasbeeh Counter App (Advanced)

A simple and interactive **Tasbeeh Counter Web App** built using HTML, CSS, and JavaScript. This app allows users to count tasbeeh digitally with additional features like sound feedback and dynamic image updates based on count ranges.

---

## 🚀 Features

* ➕ **Increment Counter** – Increase count with each button click
* 🔄 **Reset Option** – Reset counter back to zero
* 🔊 **Sound Feedback** – Plays a sound on every click
* 🖼️ **Dynamic Image Change** – Image updates based on tasbeeh count ranges
* 🎯 **Range Handling** – Displays different images for different count intervals

---

## 🧠 Concepts Used

* DOM Manipulation
* Event Handling (Click Events)
* Conditional Logic (if/else)
* State Management (count tracking)
* Media Handling (audio & images)

---

## 📂 Project Structure

* `HTML` → Structure and layout
* `CSS` → Styling and UI design
* `JavaScript` → Counter logic and dynamic updates
* `Assets (Pics & Audios)` → Images and sound files

---

## 🎯 How It Works

1. User clicks the **Add button**
2. Counter increases by 1
3. Sound plays instantly
4. Based on count:

   * 0–33 → First image
   * 34–66 → Second image
   * 67–100 → Third image
5. If limit exceeds, user is prompted to reset
6. Reset button sets count back to zero
